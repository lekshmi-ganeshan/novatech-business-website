# NovaTech Solutions – Business Website

A modern, responsive business website developed using HTML, CSS, and JavaScript.

## About the Project

NovaTech Solutions is a business website project designed to demonstrate front-end web development skills through a clean layout, responsive design, and interactive navigation.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Modern website layout
- Responsive design for mobile and desktop
- Navigation menu with mobile toggle functionality
- Hero section
- About section
- Services section with three service cards
- Contact section
- Footer
- Smooth scrolling and hover effects

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
